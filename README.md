# Yemot AI Manager

ממשק ניהול בעברית ובכיווניות RTL למערכת ימות המשיח.

## הפעלה מקומית

```bash
npm install
npm run dev
```

## פריסה ב-Vercel
ייבאו את המאגר ל-Vercel והשאירו את הגדרות Next.js כברירת מחדל.

## משתני סביבה
הגדירו ב-Vercel Project Settings → Environment Variables את פרטי הגישה של ימות המשיח. אין לשמור סיסמאות או מפתחות בקוד או בדפדפן.

## מצב הפיתוח
הממשק הראשוני כולל עץ שלוחות לדוגמה, חיפוש, תצוגת פרטי שלוחה וחלונית הוראות בשפה טבעית. חיבור פעולות הקריאה והכתיבה יושלם לאחר אימות מול תיעוד ה-API הרשמי, כדי לא לנחש כתובות או פעולות API.
